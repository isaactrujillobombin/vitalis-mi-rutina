# docs/design-thinking/

Material de la fase de Design Thinking (pendiente de añadir).

Debe recoger, como mínimo:

- El reto y el problema detectado (la soledad de las personas mayores).
- La persona de referencia y sus necesidades.
- La tarea observable que el MVP tiene que permitir.
- Las exclusiones de alcance y su motivo.

Parte de este contenido ya está resumido en [../spec.md](../spec.md) §1 y en la página `01_Brief` del Figma.
